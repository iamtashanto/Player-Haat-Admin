# Admin release notes (release/v1)
- Sign-in stays email + password + authenticator (no phone controls).
- Dashboard: 7/30/90-day range, honest "No data yet" instead of flat charts.
- New **Ratings & disputes** page (keep/remove with a reason, audit-logged), flagged organisers, and a full rating history (hidden and unrevealed included) on each user.
- Build with `VITE_API_URL` set to the real API; do not build with a local `.env` pointing at localhost.
